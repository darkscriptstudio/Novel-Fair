# Novel Fair

> **Novel Fair — First Beta Release**

NovelFair is a novel reading app that brings Bangla and English stories together in one place. Browse and search a curated catalogue, read with a customizable reader, and keep your library, bookmarks, favorites, and reading progress in sync across your devices.

## ✨ Features

### 🔎 Explore

- Home feed with featured novels
- Rotating promotional banner
- Popular writers and categories
- Discover and category screens
- Search across titles, authors, and categories
- Rich novel detail pages
- Chapter lists and author information

### 📖 Reading

- Customizable novel reader
- Continuous scroll mode
- Page reading mode
- Optional book-flip effect
- Adjustable font and font size
- Adjustable line spacing
- Adjustable content width
- Multiple reading themes
- Table of contents
- Bookmarks
- Automatic reading-position saving
- Cross-device reading synchronization when signed in and sync is enabled
- Cached chapters for offline reading
- Adult-content titles are clearly labeled and gated behind confirmation

### 📚 Personal Library

- Reading statuses:
  - Reading
  - Plan to Read
  - Completed
- Continue Reading
- Reading History
- Bookmarks
- Favorites
- Reading Statistics
- Achievements
- Daily Reading Streaks

### 👤 Account & Settings

- Email/password authentication
- Google Sign-In
- Email verification
- Appearance and theme settings
- Font preferences
- Reader preferences
- Animation controls
- Storage and cache controls
- Data synchronization controls
- Privacy settings
- In-app update mechanism

*The above feature list is based on the first beta release notes.*

## 🧪 Beta Status

NovelFair is currently in **Beta**.

You may encounter bugs, incomplete functionality, or changes to existing features. Features may also be modified or removed in future releases.

### Known Limitations

The current beta has some incomplete or placeholder functionality:

- Notification preferences and some privacy toggles are currently placeholders.
- "Clear Downloads" is currently a placeholder.
- "Rate on Google Play" is currently a placeholder.
- "Export my data" is currently unavailable.
- "Open Source Licenses" is currently a placeholder.
- Comments are not available.
- Reviews are not available.
- Payments/subscriptions are not available.
- User publishing is not available.

*These limitations are documented in the current beta release notes.*

## 🔐 Privacy & Data

NovelFair collects and processes information required to provide account, reading, synchronization, crash-reporting, analytics, notification, and update functionality.

Depending on the feature, this may include account information, profile information, reading progress, reading statistics, reading history, bookmarks, favorites, library data, and certain technical information.

Your reading data can be synchronized across devices when synchronization is enabled. Synchronization can be configured from:

> **Settings → Data Sync**

The application does not sell personal information or use personal information for behavioral advertising.

## 🔒 Security

NovelFair uses encrypted connections for communication with its services. Local application data is stored in an encrypted database, with the encryption key protected through the device's security hardware. Passwords are handled through Firebase Authentication.

APK update files are also verified using checksums before installation.
